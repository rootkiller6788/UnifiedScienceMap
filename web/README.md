# 🧮 数学声明历史地图（web）

mathlib4 **源码级**数学声明（7 类：theorem/lemma/def/class/structure/inductive/axiom）的 **16:9 科研绘图**。节点量级 **15 万+**，远看学科聚合，放大钻取到单个声明。

## 运行

`fetch('decls.json')` 需要 http 环境，**不能直接双击打开 index.html**，需起本地静态服务器：

```bash
# 方式一：Python
python -m http.server 8756 --directory web

# 方式二：Node
npx serve web -l 8756
```

浏览器打开 `http://localhost:8756`。

> 首次加载要拉取约 17.7 MB 的 `decls.json`（15.3 万节点），几秒内完成。

> `decls.json` 是**生成的产物，已 gitignore**（18MB）。克隆仓库后需先本地生成：
>
> ```bash
> node extract/extract-decls.mjs   # 离线扫描 Mathlib 源码，约 14s，输出 web/decls.json
> ```
>
> 需要仓库里带完整的 `Mathlib/` 源码（本仓库即 mathlib4 镜像）。

## 布局语义（学科簇布局）

所有节点用**同一套公式**计算二维坐标，无手工坐标。**每个学科的点聚成紧凑簇**，簇的位置 = 整体模式的圆圈位置，两种模式完全对位：

$$
x_i = \text{学科簇}：\text{该学科横槽内按时间铺开（左早右晚）} + \varepsilon_x
$$

$$
y_i = 0.7\,C(c_i) + 0.2\,D(m_i) + 0.05\,T(k_i) + 0.05\,F(i)
$$

- **X（学科簇）**：每个学科一个紧凑横槽，按学科**平均首次进库时间**从左到右排列；槽宽 ∝ √count；簇内节点按模块首次进库时间在槽内铺开（左早右晚）。整体模式圆圈圆心 = 簇的质心，网络模式的点团就在圆圈里。
- **C 社区位置**：节点所属学科（顶层目录）的平均依赖深度——决定"属于哪片大陆"。基础（Logic/Order/Data/SetTheory）在底部，抽象构造（Probability/MeasureTheory/AlgebraicGeometry/Analysis）在顶部。
- **D 依赖深度**：模块 import DAG 最长路径（Kosaraju 缩点处理 869 模块互导环后拓扑 DP），log 归一化。
- **T 类型权重**：`axiom 1.0 · inductive 0.9 · structure/class 0.85 · def 0.7 · theorem 0.4 · lemma 0.2`。
- **F 局部扰动**：确定性 hash 抖动 ∈ [−0.5,0.5]，只防重叠不改变结构。
- 最后做一次 min-max 全局拉伸，铺满 16:9 画布。
- **hover 显示真实年份**（`nodes.year`，文件级首次进库），不再由 x 反推。

## 功能

| 交互 | 说明 |
|---|---|
| 🌐/🔗 模式按钮 | 手动切换「整体模式」（学科聚合）↔「网络模式」（声明网络） |
| 滚轮缩放 | 缩放画布（整体模式缩学科块，网络模式缩节点网络） |
| 拖拽平移 | 平移画布 |
| 悬停节点 | 高亮该声明全部关联节点和连线（同领域=领域色，跨领域=两色渐变，发光），显示详情 |
| 搜索框 | 按声明名或模块名定位（如 `kernel`、`Cauchy`、`Pythagorean`），自动切到网络模式 |
| 图例 | 点击学科开关该分支显隐 |
| ⤢ 重置视图 | 回到 16:9 全局视图 |

## 两种模式（右下角按钮切换，干净无中间模糊态）

- **🌐 整体模式**：25 个学科**聚合圆块**（大陆样式）+ 学科间依赖边，干净利落的地图（切到该模式自动缩到整图）。
- **🔗 网络模式**：**全矢量绘制**每个声明节点和依赖边（无模糊栅格），按度降序 + 屏幕网格限流（每格 1 点，满格即停），保证 15 万节点任意缩放流畅又清晰（切到该模式自动放大到节点可见）。
- 模式**不随缩放自动切换**，由按钮决定；搜索定位会自动切到网络模式。
- **深放大（缩放 ≥ 8×）**：叠加显示声明名标签。

## 连线配色与悬停高亮

- **不悬停**：所有连线一律灰色细线（学科聚合边也是灰）。
- **悬停某个声明**：把它**所有关联节点和连线**显示出来并发光——
  - **同领域**连线 = 该领域色（如两个黄色节点 → 黄线）；
  - **跨领域**连线 = **两领域色线性渐变**（如蓝→黄）；
  - 关联节点：领域色光晕 + 亮环；悬停者本身：领域色光晕 + 亮白环。
- hover 用空间网格索引（O(近邻) 非 O(n)）。

## 视觉编码

- **节点/学科颜色** = 学科（黄金角色轮，25 色）。
- **节点大小** ∝ 关联度（import 依赖边越多，节点越大）。
- X 轴两端标注年份，Y 轴左侧竖排"结构深度（底=基础 → 顶=高级构造）"。

## 架构

```
web/
├── index.html   # 页面外壳 + HUD + 图例 + 搜索
├── main.js      # 渲染器：Canvas 绘制 + zoom/pan + LOD + 空间索引 + 坐标轴
└── decls.json   # 数据（列式 SoA，由 extract/extract-decls.mjs 生成，勿手改）
```

- **渲染**：Canvas 2D，节点模式全矢量绘制（按度降序 + 屏幕网格限流，每帧 ≤ 屏幕格数），边单条 path 视口裁剪，hover 用空间网格索引。
- **无布局计算**：坐标内嵌在 decls.json，前端秒开（无 Web Worker / 力导向）。
- **数据**：见 [../extract/README.md](../extract/README.md)。

## 依赖（CDN，无构建步骤）

- `d3-zoom@3`、`d3-selection@3`（jsdelivr ESM）
- 首次加载需联网拉取 CDN 与 decls.json（约 17.7 MB）。

## 已知边界

- 每个声明的 `t_i` 是**文件级**首次进库时间（同一模块内所有声明共享），非逐声明精确时间。
- 依赖边是「模块 import 近似」，非严格定理推导链；类型权重为语义化设定值。
- 未纳入 `instance`（7,759 named）/`abbrev`（2,127）/`opaque`，默认隐藏。
